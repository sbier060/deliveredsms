# Delivered Design System

Inherited layout discipline from the platform's first life; own identity.

## Identity
- **Wordmark:** "Delivered" in `#EFEEEC` with a trailing period in the
  accent green — the punctuation IS the brand mark (delivered. done.). Set in
  the system stack; no logo image until one exists.
- **Voice:** plain, technical, confident. Numbers over adjectives. No em-dash
  clutter in marketing copy; every claim checkable.

## Tokens
| Token | Value | Use |
| --- | --- | --- |
| bg | `#0A0A0B` | page background |
| surface | `#0F0E0C` | cards, code blocks |
| border | `#2E2C28` | all hairlines |
| text-hi | `#EFEEEC` | headings, emphasis |
| text-mid | `#C9C6BF` | body |
| text-lo | `#918E86` | captions, labels |
| **accent** | `#00D26A` | THE one loud thing per view |
| accent-deep | `#009E4F` | gradient partner |

Accent gradient: `#00D26A → #009E4F` (CTAs only). Never red; destructive
actions are muted gray.

## Rules
1. One loud element per view.
2. Hierarchy from size and color, never weight.
3. Two-tone headlines: bright line + muted line.
4. Left-aligned, editorial, max-w-6xl.
5. Mono for anything a developer will copy.
6. Mobile first; wide tables scroll in their own container.
